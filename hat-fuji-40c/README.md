# FujiNet Hat 40c ( old, needs bodges )

Bill Athing's bodge for this 40c hat:

```
Connect these:
    j1-9 -> j2-8
    j1-11 -> j3-15
    j1-13 -> j2-10
    j1-15 -> j2-9
r1 and r2 are removed.
```

For an example, see image `40c-bodged.webp`

This bodge is also being used by MassiveRobot
in his (tentatively-named) `jamesBrown` distro
of NitrOS9 Level 2 with FujiNet.
