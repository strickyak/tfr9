# os/

Guest operating system recipes, modules, and prebuilt assets:

- `nitros9/` — NitrOS-9 Level 1/2 recipes and imported modules (`cmds/basic09`).
- `jamesbrown-32z/` — Motorola 6809E, CoCo-2 / CoCo-3 I/O-safe overrides for `build/centipede32z-jamesbrown.dsk` (`make jamesbrown-32z-dsk`, `./run_centipede32z_jamesbrown.sh`).
- `fujinet/` — FujiNet NitrOS-9 drivers and tools (GPLv3, own `LICENSE`).
- `hatvan/`, `fuzix/`, `turbo9os/`, `rsbasic/` — Hatvan OS, Fuzix, Turbo9OS, and Radio Shack BASIC notes/recipes.
